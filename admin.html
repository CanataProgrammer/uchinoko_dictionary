GitHub と接続する

編集内容は GitHub のリポジトリ（）に直接保存されます。 保存のために、この端末で一度だけ「アクセストークン」を登録してください。 トークンはパスワードで暗号化して、このブラウザにだけ保存されます。

  1. GitHub のトークン作成ページを開く
  2. 「Repository access」で Only select repositories → このサイトのリポジトリだけを選ぶ
  3. 「Permissions」の Contents を Read and write にする
  4. 作成されたトークン（github_pat_…）を下に貼り付ける
